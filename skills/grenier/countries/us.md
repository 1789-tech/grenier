# grenier — United States (us)

Currency: $ · Write listings and replies in English. Local pickup is common and
free; shipping for smaller/valuable items.

US bias in one line: **Facebook Marketplace / Craigslist / OfferUp for local
value**, **Poshmark / Depop for fashion**, **eBay for shippable value**,
**Decluttr / Ziffit / thredUP for bulk buy-back**, **Goodwill / Buy Nothing /
Habitat ReStore for donation**, **Best Buy / municipal e-waste for dead
electronics**.

---

## Channels — where to sell / donate / recycle (for `disposition.md`)

### Sell — individually

| Channel | Best for | Notes |
|---------|----------|-------|
| **Facebook Marketplace** | Furniture, appliances, decor, bikes, tools, baby gear | The default for most local items. Huge reach, free, local pickup. |
| **Craigslist** | Furniture, appliances, "curb alert" free items, local pickup | No account friction; cash + pickup. Meet in public for safety. |
| **eBay** | Electronics, collectibles, shippable/niche items, national buyers | Fees apply; great for anything mailable with real value. |
| **Poshmark / Depop** | Clothes, shoes, accessories, fashion | Poshmark = mainstream resale; Depop = younger/vintage. |
| **OfferUp** | Local goods, similar to Marketplace | Strong in many metros. |
| **Specialized** | Trade-in for phones/tech (Gazelle, Decluttr, carrier trade-in), sneakers (StockX, GOAT) | Best price for the right category. |

### Sell — in bulk (volume, minimal effort)

- **Books / CDs / DVDs / games** → **Decluttr / Ziffit**: scan barcodes, they
  quote and pay shipping. Low per-item, zero friction.
- **Clothes in bulk** → thredUP "Clean Out" kit (mail a bag; low payout but
  effortless), or a yard sale.
- **Everything at once** → yard/garage sale to clear low-value items in a day.

### Donate

- **Goodwill / Salvation Army** — clothes, housewares, furniture, books. Some
  offer donation pickup for large items. Tax receipt available.
- **Habitat for Humanity ReStore** — furniture, building materials, appliances;
  will often pick up.
- **Buy Nothing groups** (Facebook / app) — hyperlocal give-away; a neighbor picks
  it up today. Great for good-but-cheap items.
- **Freecycle** — email-list give-away network.
- **Local charities / shelters** — for specific items (coats, kitchenware, etc.).

### Recycle / dispose (correctly)

- **E-waste** — Best Buy in-store recycling, Staples, or municipal e-waste events.
  Never in household trash.
- **Batteries, bulbs, paint** — Home Depot / Lowe's drop-offs (batteries, bulbs);
  PaintCare sites for paint; Call2Recycle for batteries.
- **Bulky items / furniture (dead)** — municipal bulk pickup (schedule with your
  city/hauler) or the transfer station/landfill.
- **Textiles (worn/damaged)** — many charities take rag-grade textiles for
  recycling; check for retailer take-back programs.
- **Household hazardous waste** (solvents, chemicals) — county HHW drop-off. Never
  down the drain or in the trash.

## Pricing — realistic value & the one move (for `pricing.md`)

### Priority mapping

| Priority | Default move | Pricing stance |
|----------|--------------|----------------|
| **max cash** | Best-fit resale channel, often item-by-item | Price near the realistic high end; accept slower sale and negotiation. |
| **balanced** | One clean listing or one bulk route | Price in the middle-low of the range so it moves in days. |
| **gone fast** | Curb alert, pickup, buy-back, donation, Buy Nothing, recycling | Price low or skip the sale if hassle beats money. |

### US channel heuristics

| Item type | Best default | When to avoid |
|-----------|--------------|---------------|
| Furniture, appliances, bikes, tools, baby gear | **Facebook Marketplace / Craigslist**, local pickup | Avoid if value < $15–20 or transport/messages will be painful. |
| Clothes, shoes, bags, accessories | **Poshmark / Depop**; bundle basics or thredUP | Avoid single low-value basics unless bundled. |
| Books | **Decluttr / Ziffit** for ordinary lots; **eBay** for valuable/rare | Avoid listing ordinary paperbacks one by one. |
| CDs/DVDs/games/consoles | **Decluttr / Ziffit** for fast cash; **eBay** for valuable items | Avoid low-value singles. |
| Electronics (working) | **eBay** for shippable value; **trade-in** (Gazelle/carrier) for phones | Avoid Marketplace for high-value shippables (fewer buyers, scams). |
| Decor, small household goods | **Marketplace** only if attractive/bundled; otherwise **Buy Nothing/Goodwill** | Avoid standalone listings under $15. |
| Broken electronics/appliances | **Best Buy / municipal e-waste** | Do not sell as working; "for parts" only for niche items. |

### Price heuristics

- **Marketplace / Craigslist / OfferUp**: some haggling is normal. Max cash → list
  ~10% above target or add "OBO". Balanced → list at target. Gone fast → price low
  or post a "curb alert" free.
- **eBay**: fixed-price with "Best Offer" is the low-effort default; factor in
  ~13% final-value fee + shipping before deciding it's worth it.
- **Buy-back (Decluttr/Ziffit/thredUP)**: expect low per-item return but near-zero
  listing work. For ordinary media/clothes, usually the correct mental-load trade.
- **Donation/give-away threshold**: under roughly **$10–15 net**, or when the item
  needs cleaning, transport, dimensions, many messages, or awkward pickup,
  recommend Buy Nothing / Goodwill / recycling unless it's part of a bundle.

### Bundling rules

- Books: split **ordinary bulk** (buy-back/donate) from **valuable few** (sell
  individually).
- Kids' clothes: bundle by **size + season**; adult basics by **size + style**, or
  donate weak brands.
- Kitchenware/decor: bundle as a "moving lot" or "kitchen starter lot".
- Toys: bundle by age/franchise only if complete and clean; otherwise donate.

## Listing — how to draft the ad (for `listing.md`)

### Title format

- Pattern: **Brand + Model + key spec + condition**.
  e.g. `Trek FX 2 Hybrid Bike - Size M - Great Condition`.
- Front-load searchable keywords. No emojis, no ALL CAPS. Title case is fine.

### Pricing norms

- On **Facebook Marketplace / Craigslist / OfferUp**, some haggling is normal —
  price ~10% above target, or add "OBO" (or best offer) if you want offers.
- On **eBay**, decide fixed-price vs. auction; fixed with "Best Offer" is the
  low-effort default. Factor in ~13% final-value fee + shipping.
- Round to clean numbers ($25, $40). "Firm" signals no haggling.

### Categories (by platform)

- **Facebook Marketplace** — pick the native category (Furniture, Electronics,
  Appliances, Bicycles, Clothing…). Set condition and location.
- **eBay** — choose the exact item category; fill item specifics (brand, model,
  size) — they drive search.

### What buyers expect

- **Local pickup** by default (cash, meet in a public place / porch pickup) or
  shipping for smaller items. State which.
- Honest condition; note defects and whether electronics power on.
- Dimensions for furniture, size for clothing, working status for electronics.
- For Craigslist/Marketplace, expect "is this still available?" — that's normal.

### Example block

```
TITLE: Solid Oak Coffee Table - 44x24 in - Great Condition
PRICE: $70 (range: $50–$95) OBO
PLATFORM: Facebook Marketplace — local, free, big reach
CATEGORY: Furniture > Tables

Solid oak coffee table, 44x24x18 in. A few light surface scratches on top
(see photos), sturdy frame. Selling because we're moving.
Local pickup only, cash.

Handover: porch pickup, Austin 78704
```
