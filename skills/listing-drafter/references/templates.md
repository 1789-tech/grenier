# Gabarits d'annonces

## Leboncoin meuble / objet maison

Titre : `[Objet] [marque/modèle] - [dimension] - [état]`

Description :

- vendu cause tri/déménagement ;
- état général + défauts visibles ;
- dimensions ;
- conditions de retrait ;
- prix ferme ou negociable.

## Vinted vêtement / lot

Titre : `[Catégorie] [marque] [taille] - [état]`

Description :

- taille et coupe ;
- état, taches/usure s'il y en a ;
- composition si connue ;
- envoi via Vinted ;
- reduction possible si lot.

## Tech

Titre : `[Marque] [modèle exact] [capacité] - [état]`

Description :

- modèle exact et accessoires ;
- batterie/fonctionnement ;
- état cosmétique ;
- facture/boite si disponibles ;
- réinitialisation avant vente.
