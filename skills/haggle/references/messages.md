# Messages rapides

## Négociation

- Contre-offre : `Je peux faire [prix] EUR si départ rapide.`
- Prix ferme : `Le prix est ferme pour l'instant, merci.`
- Lot : `Je préfère vendre le lot complet ; je reviens vers vous si je sépare.`

## Rendez-vous

- Confirmation : `On confirme [jour] à [heure] à [lieu] ?`
- Retard : `Je peux attendre jusqu'à [heure]. Après, on reprend un autre créneau.`
- Annulation : `Pas de souci, je le remets disponible.`

## Sécurité

- Paiement : `Paiement au moment de la remise, merci.`
- Envoi : `Je passe uniquement par l'envoi protégé de la plateforme.`
